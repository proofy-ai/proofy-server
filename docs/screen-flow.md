# 화면 구성과 사용자 프로세스 (A-lite 웹앱)

> 청년 지급정지 소명 도우미 · 모바일 우선 웹앱
> 작성일 2026-11-21 · 마감 11/23(월) 17:00
> 관련 문서: `docs/contract.md`(API 계약 정본), `docs/agent-design.md`

## 서비스 위치

지급정지된 계좌의 명의인이 은행에 이의제기할 때 서류를 직접 준비해야 한다. 우리 서비스는 증빙을 읽고 정리해서 소명서 초안과 부족한 서류 안내를 만든다. 접수와 심사는 은행이 하고, AI는 판정하지 않는다.

## 이의제기 절차와 서비스가 돕는 지점

| 단계 | 내용 | 출처 | 서비스 역할 |
|---|---|---|---|
| 1. 지급정지 | 은행 등이 계좌 전부를 지급정지하고 명의인에게 통지 | 법 제4조 (원문 확인) | 해당 없음 |
| 2. 채권소멸절차 공고 | 금감원이 공고하고 이의제기 방법·절차를 함께 알림 | 법 제5조 (원문 확인) | 공고일 입력으로 기한 계산 |
| 3. 이의제기 | 지급정지일부터 공고일 기준 2개월 전까지 은행에 제출. 서류는 이의제기신청서(별지 제4호), 사기이용계좌가 아니라는 증명자료, 신분증 사본 | 법 제7조, 시행령 제7조 (원문 확인) | 소명서 초안, 부족한 서류 안내 |
| 4. 심사 | 원칙 5영업일 이내. 보완이 필요하면 5영업일 연장, 재보완이면 3영업일 더 연장 | [아시아경제 2026.5.3](https://view.asiae.co.kr/article/2026050306453019512) (기사 원문 확인, 금감원 원문 미확인) | 제출 후 흐름 안내 |
| 5. 결과 | 해제 또는 불수용. 피해자가 이의제기를 통보받은 날부터 2개월 전에는 해제하지 않지만, 객관적 자료로 충분히 소명하면 해제할 수 있음 | 법 제8조 ② (원문 확인) | 해당 없음 |

법 원문: [국가법령정보센터](https://www.law.go.kr/법령/전기통신금융사기피해방지및피해자산환급에관한특별법)

## 화면 흐름 (6개)

```text
홈 → 내 상황 → 사연·증빙 → 분석 중 → 결과 → 제출 가이드
 ↑___________________________________________|  결과·제출 가이드에서 홈으로
```

| # | 화면 | 사용자가 하는 일 | 보여주는 것 |
|---|---|---|---|
| 1 | 홈 | 시작하거나, 진행 중인 건을 이어서 하거나, **샘플로 체험한다** | 소개, 절차 타임라인, 필요한 서류 요약, 진행 중인 건 카드, **"샘플로 체험하기"**(급여·물품 거래 중 선택 → 서류가 채워진 3번 화면으로), "시연용 서비스이며 예시는 합성 데이터" 안내 |
| 2 | 내 상황 | 지급정지 통지일, 공고일(모르면 건너뜀), 문제된 입금 유형(급여 또는 물품 거래), 입금액, 과거 지급정지 이력 여부를 입력한다 | 이의제기 **남은 기한 D-day**, 유형별 안내 |
| 3 | 사연·증빙 | 거래 경위를 짧게 입력하고 유형별 체크리스트에 맞춰 사진을 올린다 | 유형별 서류 예시 체크리스트, 거래내역서에 **"AI 분석에 필요"** 배지(없으면 분석 시작 불가), 업로드 영역 위에 **"실제 서류 대신 샘플(합성) 서류만 올려 주세요" + [샘플 서류 받기]**, 신분증은 받지 않고 "별도 첨부" 안내 |
| 4 | 분석 중 | 기다린다 | 단계 표시: 글자 읽는 중 → 거래내역과 대조 중 → 초안 작성 중 (문구는 서버 `stages[].label`) |
| 5 | 결과 | 탭 3개를 확인하고 초안을 수정한다 | **탭 A 증빙 대응표**: 주장, 증빙, 거래내역 연결과 어긋나는 부분 경고. **탭 B 부족한 서류**: 체크리스트. **탭 C 소명서 초안**: 편집 가능, 증빙 없거나 **자료와 어긋난** 내용은 "확인 필요" 표시, 문장마다 "직접 확인했어요" 체크. 상단에 D-day 고정 |
| 6 | 제출 가이드 | 최종 점검 후 초안을 복사하거나 저장한다 | 낼 서류 3종, 은행에 직접 제출, 제출 후 흐름(심사 5영업일, 보완 요구 시 기한 안에 재제출), 거짓 이의제기 처벌 경고. **확인하지 않은 문장이 남아 있으면 복사·저장 전에 확인창** |

### 화면 3의 유형별 서류 예시

[한국일보 2026.5.3](https://www.hankookilbo.com/news/article/A2026050313580002729) 기사에서 확인한 두 유형만 쓴다.

| 유형 | 제출 서류 |
|---|---|
| 급여 입금 | 급여 입금내역 + 건강보험자격득실확인서 또는 재직증명서 중 하나 |
| 물품 거래 대금 | 사업자등록, 거래상대방과의 대화내역 + 계약서, 세금계산서, 거래명세서 중 하나 |

위 표는 기사 근거의 제출 서류다. 이와 별도로 **문제된 입금이 보이는 거래내역서**는 AI가 사연과 대조하는 데 필요해서 두 유형 모두 분석 시작 조건으로 둔다(급여 유형은 "급여 입금내역"이 같은 서류). 법령·기사상 의무 서류로 표시하지 않고 "AI 분석에 필요" 배지로 구분한다(물품 거래는 `ANALYSIS_INPUT` 묶음). 근거: `docs/contract.md` 4.2, 4.9.

물품 거래 유형의 서류 기준(사업자등록 등)은 사업자를 전제로 하므로, 안내와 시연은 **청년 1인 온라인 판매 사업자**의 판매 대금으로 한다. 개인 간 중고거래는 서류 기준을 확인하지 못해 다루지 않는다.

### 샘플 체험 (심사자용)

심사위원은 합성 서류 없이 처음부터 입력할 수 없으므로, 홈의 "샘플로 체험하기"로 합성 서류가 들어간 사건을 바로 만든다(`POST /cases/sample`). 3번 화면에서 바로 "분석 시작"을 누르면 4~6번을 모두 볼 수 있다.

| 시나리오 | 보여 주는 것 |
|---|---|
| 급여 | 입금 금액·날짜 일치, 근무 사실 근거 → 확인 필요 문장이 적은 깔끔한 흐름 |
| 물품 거래(1인 판매 사업자) | 대화 속 합의 금액(12만 원)과 입금액(15만 원) 불일치 → 탭 A 경고, 탭 C "확인 필요", 거래명세서 없음 → 탭 B |

### 홈 화면 구성

| 영역 | 내용 |
|---|---|
| 상단 | "내 계좌가 지급정지됐나요?"와 **이의제기 준비 시작** 버튼 |
| 진행 중인 건 카드 | 기한 D-day, 현재 단계, **이어서 하기** 버튼 |
| 절차 한눈에 | 지급정지 → 채권소멸 공고 → 이의제기(공고일 기준 2개월 이내) → 심사(원칙 5영업일) → 결과, 현재 위치 표시 |
| 필요한 서류 요약 | 이의제기신청서, 소명자료, 신분증 사본 |
| 안내 | AI는 판정하지 않고 서류 준비만 돕는다는 문구, 거짓 이의제기 처벌 안내 |

## 사용자 친화 원칙

- 한 화면에 질문 하나, 상단 진행 표시줄, 쉬운 말(법률 용어는 괄호로 설명)
- 기한 배지(D-day)를 2번 화면부터 계속 보여준다. 이 서비스에서 가장 급한 정보다.
- AI가 못 읽은 서류와 모순은 숨기지 않고 "직접 확인" 항목으로 보여준다.
- 로그인은 없다. 진행 중인 건은 브라우저 저장(localStorage)에 한 건만 둔다.
- 하단 탭바는 두지 않는다. 흐름이 한 방향이라 홈 버튼 하나로 충분하다.

## 범위 결정

- **시연 유형은 급여와 물품 거래(1인 판매 사업자) 두 가지로 한정한다.** 서류 예시가 확인된 유형이 이 둘뿐이다. 개인 중고거래 서류 기준은 확인하지 못했다.
- **필수 화면은 2~6번과 홈의 "샘플로 체험하기" 버튼이다.** 심사자가 체험할 입구라서 빼지 않는다. 홈의 나머지는 마지막에 만들어도 된다.
- **시간이 부족하면 뺀다:** 홈의 진행 중인 건 카드, 6번의 PDF 저장
- **소액 특례 안내는 P0에서 뺀다.** 기준 금액과 이력 기간을 확인하지 못해 계산할 수 없다.
- **시연은 합성 데이터만 쓴다.** 홈과 3번 화면에 안내를 둔다(해커톤 AI 활용 기준 제7조).
- **알림(푸시, 문자)은 이번 범위가 아니다.** 결과 화면에 기한 안내 문구와 D-day 표시만 넣고, 알림은 확장 가능성 항목에 적는다.

## 확인하지 못한 것

- 금감원 보도자료 원문과 이의제기 유형별 공통 소명자료의 전체 목록. 현재는 기사로 확인한 두 유형만 있다.
- 수용과 불수용의 판단 기준, 불수용 시 불복 절차. 공개된 근거가 없어서 도구가 수용 가능성을 예측하지 않는다.
- 접수 방법과 창구(온라인 가능 여부는 은행마다 다를 수 있음).
- 2026년 5월 표준화(5영업일 처리기한)가 지금 실제로 시행 중인지. 기사는 "5월 중 은행업권부터 시행" 계획을 전한 것이다.
- 소액 특례의 기준 금액과 과거 이력의 기준 기간.
- 은행별 실제 처리 기간 수치는 본문을 읽지 못해서 쓰지 않았다.
