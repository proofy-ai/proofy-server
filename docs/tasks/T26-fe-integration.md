## 범위

배포 FE(https://proofy-app.pages.dev) + 배포 BE(https://proofy-server.onrender.com)에서 화면을 눌러 확인한다.

- 새 브라우저(로그아웃 상태)에서 test01·test02를 체험 계정 선택 → 3번 → 분석 → 결과 → PDF까지 끝내 보기
- 시연 검증 ⑤: 소명서 초안을 고치면 별지 제4호 PDF "이의제기 사유"에 반영되는지
- AI 검토(v0.8 `agentReview`): FE가 흐름을 정리해 반영한 뒤 의견·근거 조항 칩·질문이 보이는지, 답하고 다시 분석 → 4번 → 다시 AI 검토까지
- 직접 고친 초안이 있을 때 다시 분석하면 덮어쓰기 확인창(`409 DRAFT_HAS_EDITS`)이 뜨고, 확인하면 이어지는지
- 체험 계정을 다시 눌렀을 때 새 사건을 만들지 않고 이어서 하는지(FE `bc614b9`)
- 만료·삭제된 사건(401·404)을 열면 목록에서 정리되는지
- 배포 주소끼리 연결(CORS), 업로드(이미지·PDF)
