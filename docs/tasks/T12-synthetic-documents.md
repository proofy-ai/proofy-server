### 서류 내용(모든 이름·번호·기관은 가상)

공통: 각 서류 맨 위 띠에 "합성 데이터 · 시연용 · 실제 인물·기관과 무관". 대각선 워터마크는 OCR을 방해해서 쓰지 않는다. PDF 메타데이터·PNG `tEXt`에도 같은 표시. 실제 은행·국세청·메신저 모양(로고·직인·색)을 흉내 내지 않는다.

**test01 GOODS** (예금주·대표자 정하늘, 상호 "하늘가죽공방")
- 거래내역서(텍스트 PDF, A4 1쪽): 은행 "샘플은행(가상)", 계좌 `999-0000-1234-56`, 조회기간 2026-11-01~11-14. 표 열 = 거래일시 · 구분 · 금액 · 잔액 · 거래상대/적요. 행은 가짜 분석기와 **정확히 같은 3행**
  - 2026-11-03 입금 32,000 박서진 / 2026-11-08 입금 150,000 김민수 / 2026-11-10 출금 45,000 체크카드 결제
  - 이름은 원문 그대로 두고 마스킹(T14)이 `박*진`·`김*수`로 가린다. 출금 적요에 "택배"를 넣지 않는다(택배 발송이 "진술만"으로 남게)
- 대화내역(PNG 720×1280, 말풍선): 거래처 김민수 사장과 11/6~11/7 대화. 김민수가 "3개 12만원에 할게요"라고 말하고, 그 뒤에 15만 원을 설명하는 말(배송비 등)은 넣지 않는다. 택배·명세서 이야기도 넣지 않는다. 이 문구를 위에서 13번째 줄(가짜 분석기 `region_index=12`)에 두도록 배치하되, OCR 줄 번호는 보장하지 않는다(실제 분석은 자기 줄 번호를 쓴다)
- 사업자등록증명(PNG 1240×1754): 상호·대표자·사업자번호 `123-45-67890`·개업일 2025-03-02·업태 소매업·종목 전자상거래. 발급기관은 "(가상) 발급기관", 직인 없음

**test02 UNEXPECTED** (예금주 한도윤)
- 거래내역서(텍스트 PDF): 가짜 분석기와 같은 2행. 2026-11-09 출금 23,000 체크카드 결제 / 2026-11-12 입금 100,000 이준호. 11/12 뒤 출금 없음(→ "그대로 두었다" 일치). 사연의 11/11과 하루 다름(→ `DATE` 어긋남)
- 협박 문자(PNG 720×1280, 문자 앱 모양): 보낸 번호 `010-0000-4821`, 11/13 수신. 첫 말풍선이 "20만 원 보내면 신고 취하해 줄게"(가짜 분석기 `region_index=3` 위치), 뒤에 "오늘 안에 답 없으면 그냥 둔다" 정도 한두 줄

### 정할 것

1. **스크립트를 레포에 두고 결과를 커밋**(추천). 서류를 다시 만들 수 있고 소개서에 "합성 데이터 생성 방법"을 보여 줄 수 있다. 서버·Docker에는 영향 없음
2. **글꼴:** Noto Sans KR(SIL OFL) 가변 글꼴을 이 PC의 `C:/Windows/Fonts/NotoSansKR-VF.ttf`에서 읽고 **글꼴 파일은 레포에 올리지 않는다**(약 10MB). PDF에는 쓴 글자만 들어가고(OFL이 허용), PNG는 그림이라 글꼴이 아니다. 스크립트에 `--font` 옵션. 11/22 확인: reportlab에 가변 글꼴이 등록되고 `pypdf`로 한글이 그대로 다시 읽힘, Pillow에서 굵기(Regular·Medium) 선택 가능. PDF 쪽 굵기는 기본값이라 너무 가늘면 PNG처럼 굵기 지정 방법을 찾고, 안 되면 그대로 둔다(글자 추출에는 영향 없음)
3. **거래 행은 가짜 분석기와 정확히 같게**(추천). 행을 더 넣으면 실제처럼 보이지만, 실제 분석과 가짜 분석(및 T11 미리 만든 결과)의 거래 목록이 달라진다
4. **test02 신고 접수증(`OTHER`)은 넣지 않는다**(추천). 넣으면 계약 4.3.1 표의 "바로 은행에 알렸다 = 진술만, `INCIDENT_REPORT` `MISSING`"과 어긋난다. 피해 경위 묶음(`VICTIM_CONTEXT`)은 협박 문자로 이미 시연된다
5. **PNG 글자 인식 확인:** 이 PC에 Tesseract가 없어 OCR은 T13·배포(Docker)에서 확인한다. T12에서는 글자 크기(본문 26px 이상)·대비를 OCR에 유리하게 두고 사람이 눈으로 확인
6. **시간 상한:** 1.5시간
