# T23 법령 조회 도구

- 단계: 3단계 실제 AI(계약 v0.8, 11/22 추가) · 예정: 11/22 오후 · 상태: 대기 · 이슈: 없음 · PR: 없음

## 범위

- 법령 원문(통신사기피해환급법·시행령·별지 제4호, `docs/legal/`)을 조항 단위로 나눈다. Docker 이미지는 `app/`만 담으므로 원문은 `app/` 아래에 둔다
- 대조 에이전트 도구 2개: `search_law(reason, query)` → 조항 목록, `get_law_article(reason, ref)` → 조항 원문. step `TOOL_CALL` "법령 조회"
- 이번 실행에서 돌려준 조항을 모아 두고, 인용이 그 원문에 있는지 대조하는 함수(T24 의견 검증에서 씀)
- 조항 `ref` → 화면 이름 `label`(예: "법 제7조 제1항 제2호")

## 제외

- 임베딩·벡터 검색(조항 수가 적어 낱말 검색으로 충분)
- 판례·다른 법률(전자금융거래법 등)

## 완료 조건

- 도구가 조항을 돌려주고, 인용 대조가 공백을 무시하고 동작한다(단위 테스트)
