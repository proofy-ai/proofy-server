## 받은 방법

`law.go.kr/법령/…` 페이지는 본문을 스크립트로 불러와 그대로는 글자가 없다. 본문은 아래 주소로 받고, HTML 태그를 지워 글자만 남겼다.

- 법: `https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=290245&chrClsCd=010202&urlMode=lsInfoP&ancYnChk=0`
- 시행령: `https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=290281&chrClsCd=010202&urlMode=lsInfoP&efYd=20261001&ancYnChk=0`
- 별지 제4호서식 PDF: `https://www.law.go.kr/LSW/flDownload.do?gubun=&flSeq=170198443&bylClsCd=110202` (`pdftotext -layout`로 글자 추출)

사람이 읽을 주소: [법](https://www.law.go.kr/법령/전기통신금융사기피해방지및피해자산환급에관한특별법) · [시행령](https://www.law.go.kr/법령/전기통신금융사기피해방지및피해자산환급에관한특별법시행령)

## 이의제기와 관련된 조항

| 조항 | 요지 |
|---|---|
| 법 제7조① | 공고일 기준 2개월 안에 이의제기. 사유 3가지: 1호 사기이용계좌 아님, 2호 재화·용역 대가 등 정당한 권원(객관적 자료, 알았거나 중대한 과실로 몰랐으면 제외), 3호 피해자산 편취에 쓰인 계좌 아님(객관적 자료) |
| 법 제8조①2호 단서 | 3호 이의제기는 피해자산을 뺀 금액만 종료(일부 해제) |
| 법 제8조②2호 | 피해자가 이의제기를 통보받은 날부터 2개월 전에는 해제하지 않음. 단 객관적 자료로 충분히 소명하면 해제 가능 |
| 법 제9조① | 공고일부터 2개월이 지나면 채권 소멸 |
| 시행령 제7조 | 별지 제4호서식 + 증명 자료 + 신분증 사본을 계좌 관리 금융회사에 제출 |
| 시행령 제8조① | 종료 사유: 피해자 전원 취소, 수사기관 철회, 수사기관이 관련 위반 사실 없음을 확인 등 |
| 별지 제4호서식 | 칸: 신청인, 지급정지 계좌, **이의제기 사유(구체적으로 기재합니다)**, 첨부 2종, 수수료 없음 |
