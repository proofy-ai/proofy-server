# 법령 원문 (에이전트 법령 조회용)

`docs/legal/README.md`에 적은 방법으로 받은 현행 원문 글자 파일이다(11/22). 배포 이미지는 `app/`만 담으므로 여기에 둔다(T23).

- `law_20261002.txt` 통신사기피해환급법, `decree_20261001.txt` 같은 법 시행령, `form4_20260929.txt` 시행령 별지 제4호서식
- `app/agent/law.py`가 조 단위로 나눠 `search_law`·`get_law_article` 도구로 돌려주고, AI 인용을 이 원문과 대조한다
- `app/services/legal.py`(T21)의 인용 테스트도 이 파일을 기준으로 한다
- 파일을 고치지 않는다. 법령이 바뀌면 새 날짜 파일로 다시 받는다
